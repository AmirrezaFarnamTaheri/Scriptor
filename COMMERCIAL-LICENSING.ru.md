# Коммерческое лицензирование

Scriptor доступен по лицензии **GNU AGPL-3.0-or-later**. AGPL разрешает коммерческое использование, изменение, распространение и эксплуатацию по сети при соблюдении её условий. Проект не добавляет к AGPL отдельного ограничения «только некоммерческое использование».

Отдельная коммерческая лицензия может быть полезна организации, которая хочет:

- распространять proprietary-продукт или closed-source производную без обязательств AGPL;
- эксплуатировать изменённый сетевой сервис без предоставления соответствующего исходного кода, требуемого AGPL;
- согласовать условия warranty, indemnity, support, service-level, integration или redistribution.

Коммерческая лицензия — это **альтернатива** AGPL, а не требование для коммерческой деятельности, которая полностью соблюдает AGPL.
