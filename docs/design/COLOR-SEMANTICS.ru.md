# Семантика цветов и владение

**Статус:** действующий дизайн-контракт

Scriptor разделяет цветовые значения по зонам ответственности, чтобы состояние продукта не кодировалось бесхозными литералами.

## 1. Тема и семантические цвета UI

Интерактивное состояние, статус, выделение, фокус, предупреждения, ошибки, успех, границы и поверхности приложения должны использовать именованные CSS custom properties. Текущий compatibility layer предоставляет переменные вроде `--primary`, `--danger`, `--success`, `--selected`, `--surface` и `--border`; многоуровневая система токенов в `src/styles/tokens/` владеет соответствующими примитивными и семантическими палитрами.

CSS компонентов и React-код рендеринга не должны вводить новый hex-цвет для обозначения состояния приложения или взаимодействия. Вместо этого добавьте либо сопоставьте токен.

## 2. Палитры контента и визуализаций

Persisted или созданные пользователем визуальные данные отличаются от chrome приложения. Заливки/обводки блоков Canvas, цвета sticky notes, аннотаций, палитры серий/папок graph, определения syntax/editor themes, defaults экспортируемого SVG и выбираемые пользователем палитры темы могут содержать литеральные цвета, если литерал является частью формата контента или именованной палитры. Эти значения нельзя повторно использовать как неявный цвет статуса приложения.

## 3. Fallback

Компонент не должен обходить владение токенами сырым семантическим fallback вроде `var(--danger, #b42318)`. Обязательные application tokens определены контрактом темы. Content renderers могут использовать стабильные литеральные fallback при загрузке пользовательских данных без стиля, потому что эти значения описывают содержимое документа, а не состояние UI.

## 4. Canvas API

SVG presentation attributes могут напрямую ссылаться на CSS variables. Canvas 2D API требуют разрешённых цветов, поэтому application-semantic Canvas colors читаются из вычисленных custom properties активного элемента. Палитра визуализации допустима только как fallback рендеринга, а не как источник семантики статуса.
