## 4. Findings (standard format, condensed)

### D1 — Declared rustfmt gate never enforced; HEAD violates it
- **Evidence:** `ci.yml` contains clippy + tests but zero fmt steps (read in full); README L71-72, CONTRIBUTING L56, VERIFICATION L48 declare it; `cargo fmt --check` at HEAD emitted **41 hunks** in 8 files (publish-runner ×6 files heaviest, plus capture/fetch, capture/to_markdown, indexer/parse, indexer/search, desktop publish.rs). Drift introduced by merges `05e6db8` (08-21) and `c124746` (08-22).
- **Tier:** Evidence (commands + outputs captured). **Severity:** High · **Effort:** S · **ROI:** High.
- **Applied fix:** `cargo fmt --all` (whitespace-only diff), CI `Rustfmt workspace check` step (mirrors existing invoke-logged pattern), CHANGELOG entry. **Validation:** `cargo fmt --all --check` exit 0 post-fix; action-pins & docs-contracts validators re-run green after workflow edit.

### D2 — Vault-open race kills Git panel status (CI-red regression)
- **Evidence chain:** last green CI `c124746`; first red `8810d1b`. That commit rewrote `useWorkspaceGit` to tag state `{vaultId}` and reject responses where `vaultIdRef.current !== targetVaultId`. `openVaultAt` calls `refreshGit()` through the **pre-`setVault` closure**, so `targetVaultId` is the old/null id while the ref has already advanced when the response lands (and if the response lands pre-commit, the render-side filter drops it instead) — both interleavings deterministically yield `status === null`. CI job log shows the exact downstream symptoms: `.health-subtitle`/`.git-changes`/checkbox assertions fail, Resolve buttons absent, 120 s click timeouts. Local pre-fix rerun reproduced failures 1:1.
- **Tier:** Evidence (reproduction + fix differential). **Severity:** Critical · **Confidence:** High · **Effort:** M · **ROI:** High.
- **Applied fix (behavior-preserving hardening, race eliminated):**
  - New `src/hooks/workspace-git-status.ts`: `WorkspaceGitStatusController` stores status/error **per-vault slot** (bounded to 3, active vault pinned), sequences refreshes via the existing `OperationGuard`, accepts an explicit target id, exposes `subscribe/getSnapshot` for `useSyncExternalStore`. Cross-vault safety became structural instead of timing-dependent.
  - `useWorkspaceGit.ts` rewritten as thin adapter (same public return shape); loading state now truthful during first-read windows ("cannot claim not-a-repository before its own status exists").
  - `useVaultWorkspace.openVaultAt` passes `refreshGit(opened.vault.id)` explicitly — immune to render-timing.
  - Regression guards: `workspace-git-status.test.ts` (6 node:test cases incl. the exact open-race interleaving), runnable via strip-types harness and auto-discovered by `run-source-tests.mjs`.
- **Validation:** unit 6/6; `tsc -b` clean; changed-file ESLint warning-zero; Playwright `git.spec.ts` **7/7**, Git-filtered polish spec **5/5** (the two CI-red tests included).

### D3 — Tests mutate tracked fixture databases
- **Evidence:** `git status` showed `packages/test-fixtures/vaults/{knowledge-edge-cases,minimal}/.scriptor/cache/index.sqlite` modified *before* this session began; still dirty after the full local Rust suite (38 binaries ran against them). Binary churn in `git diff`.
- **Impact:** accidental commits of cache state; nondeterministic review noise; contradicts "recoverable mutation" ethos at repo level.
- **Recommendation (owner decision required):** either stop tracking `**/.scriptor/cache/**` inside fixture vaults (generate on first open) or point indexer tests at temp copies. Effort S–M.

## 5. Peer Benchmarking (brief, knowledge-based)

Comparable local-first Markdown workspaces (Obsidian, Logseq, Zettlr, Typora) generally ship richer plugin ecosystems but none expose Scriptor's level of machine-checked governance (authorization inventories, generated IPC contracts, immutable release-evidence chains). Two portable patterns worth stealing:
1. **Fixture immutability** (property of well-run Tauri/Electron repos): tests never write into tracked trees — addresses D3 directly.
2. **Gate-as-code parity checks**: a meta-validator asserting every "required check" string appearing in *.md appears in some workflow (would have caught D1 mechanically). Effort S, natural extension of existing `docs-contracts.mjs`.

Transformation horizon (already half-built here): extend the intent/outcome hash-chain pattern from MCP writes into a unified mutation journal for Git + backup + publish so "what will change" previews share one auditable primitive.
