# Workspace composition verification

The desktop shell now composes writing, source files and reviewed feature/plugin workspaces through a bounded leaf layout. Twenty-four validated references can occupy main and side groups. Selection, ordering and docking persist per vault. Restoring a tab restores its reference and an explicit activation prompt; it never starts Python, compilation, synchronization or plugin commands.

Mounted tabs retain drafts while hidden; moving a feature/source leaf changes placement without remounting its owner. Closure invokes only that leaf's owners. Source decisions, live Overleaf dialogs, fresh Python runs and failed persistent shutdown block unsafe closure. Native vault transitions still own shutdown and origin checks. Multiple dirty source files reveal and settle their vault-switch decisions sequentially. Refusal and capacity feedback are accessible and localized, and controls lock during pending transitions.

The module manager uses validated registered manifests and current registry policy. Opening requires enabled/read/vault consent with safe mode off. Toggles and profiles update authority before preferences. Plugin revocation removes launch authority immediately. Declarative plugin content and routes retain their existing validation; arbitrary privileged HTML is not added.
