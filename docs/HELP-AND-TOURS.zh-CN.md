# 上下文帮助、问答与分步指南

[English](HELP-AND-TOURS.md) · [فارسی](HELP-AND-TOURS.fa.md) · **简体中文** · [Русский](HELP-AND-TOURS.ru.md) · [Deutsch](HELP-AND-TOURS.de.md) · [Español](HELP-AND-TOURS.es.md)

## 产品约定

帮助功能离线运行，仅提供只读说明。它解释当前应用，不是 AI 客服聊天、自动操作员或权限代理。任何步骤都不会执行命令、发送邮件、启用插件、运行代码、发布、恢复或删除数据。完成指南仅表示读完说明，不代表实际操作已经成功。

权威目录位于 `src/lib/help/catalog.ts`。每条指南都记录入口、前提条件、影响范围、成熟度、源代码归属、上下文选择器、步骤、问答、关联主题和展示策略。小部件与停靠面板同样拥有对应主题。尚不可用的功能仍可搜索，但会明确说明前提，不会自动启用。

## 展示时机

首次启动只显示简短的工作区介绍，可以跳过，也可以通过现有入门入口或帮助再次查看。

复杂功能首次使用时，可显示一条小型、可关闭、非模态邀请，例如工具栏定制、引用、知识工作台、关系图、画布、任务、看板、阅读器、插件、Google、Gmail、AI、MCP、资源同步、Portal、快速记录、外观、停靠面板、历史、备份和导入。同一时间最多一条，每个功能在本地帮助档案中只邀请一次。邀请不会抢占焦点，也不会自动启动完整教程。

恢复、冲突、权限、代码执行、重命名、应用提案和高级设置仅在用户请求时提供指南。日常写作和导航小部件也不会自动弹出教程。所有详细分步指南都由用户主动启动。

关闭首次使用邀请不会关闭帮助。退出保留当前步骤；只有明确完成才标记为已读。重新开始仅重置当前指南。重置全部进度需要确认，且不会更改笔记、账户、凭据或应用设置。

## 交互与无障碍

F1 优先选择当前焦点所在界面，其次是最近交互的界面，最后回退到工作区概览。标题栏问号直接打开对应主题。帮助对话框拥有可访问标题、关闭控件、独立 Tab 顺序和最高层 Escape 处理；下层面板保持打开，关闭帮助后会尽可能将焦点返回调用控件。

“显示此控件”会关闭帮助，只滚动显示或聚焦已经存在的控件，不会点击它、打开隐藏功能或授予权限。找不到目标时，会说明入口和前提条件，不会悄悄跳到下一步。指南是文本，不是可执行 HTML。搜索词、笔记、消息、路径和凭据都不会被收集或发送。

帮助控件支持英语、德语和波斯语。详细指南正文目前以英语编写，并明确标记 `lang=en`、`dir=ltr`。界面会显示本地化说明，不会把未翻译正文冒充已本地化内容。以后增加翻译必须保持主题 ID 稳定及内容等价。

## 持久化与验证

进度使用有界、带版本的本地键 `scriptor:help-guides:v1`。未知主题及无效步骤会被拒绝或规范化。存储被禁止、已满或损坏时，帮助仍以内存会话方式工作并给出警告。指南进度与入门完成状态、权限及真实任务结果相互独立。

`src/lib/help/help.test.ts` 检查目录完整性、策略、搜索、进度、存储失败、重新加载和请求验证。浏览器测试应覆盖在现有对话框上调用、输入时按 F1、Escape 与焦点恢复、邀请关闭、手动重放、目标缺失、尺寸调整、缩放、RTL 以及不触发自动变更。新增界面必须注册指南或明确关联已有主题，并验证选择器可达性。
