# Интеграции Google

[English](GOOGLE_INTEGRATIONS.md) · [فارسی](GOOGLE_INTEGRATIONS.fa.md) · [简体中文](GOOGLE_INTEGRATIONS.zh-CN.md) · **Русский** · [Deutsch](GOOGLE_INTEGRATIONS.de.md) · [Español](GOOGLE_INTEGRATIONS.es.md)

Экспериментальные интеграции настольного приложения связывают Drive, Docs, Calendar, Tasks и Gmail с локальным хранилищем. Источником истины остаются файлы Markdown. Удалённые изменения проверяются перед применением; подключение аккаунта не запускает автоматическую синхронизацию всего хранилища.

## Настройка и подключение

Откройте **Settings → Integrations**, укажите публичный идентификатор OAuth-клиента Google для настольного приложения и сохраните настройки перед открытием рабочего пространства интеграции. Для работы с Drive или Gmail синхронизацию Calendar можно оставить выключенной.

В проекте Google должны быть включены API выбранных сервисов и настроен OAuth-клиент для устанавливаемого настольного приложения. Следуйте [инструкции Google](https://developers.google.com/identity/protocols/oauth2/native-app) по настройке проекта, экрана согласия и клиента. Scriptor открывает системный браузер для получения согласия. В настройках хранилища указывайте только идентификатор клиента, никогда — секрет клиента или токен доступа.

Подключения независимы: Drive и Docs используют одно, Calendar и Tasks — другое, Gmail — отдельное. Подключите нужные группы и проверьте показанную учётную запись. Для Gmail также необходимо включить его плагин. Токены хранятся в системном хранилище ключей; публичный идентификатор клиента и выбранные ресурсы — в конфигурации локального хранилища.

## Передача Markdown через Drive или Docs

Откройте **Drive collaboration** через палитру команд. Выберите доступную папку, введите её ID вручную или создайте папку после проверки запроса разрешения на запись. Выберите способ передачи и нажмите **Save folder and transport**, чтобы сохранить выбор для этого хранилища.

JSON-записи Drive и непрозрачные записи Google Docs содержат неизменяемые ревизии Markdown. Формат записей Docs сохраняет исходные байты Markdown; он не превращает документ в редактор форматированного текста. Проверьте удалённую ревизию и разрешите конфликты перед локальным применением. Передача ревизии — явная операция записи у провайдера.

Обычные документы Google можно просматривать в выбранной папке. Преобразование в текст — отдельный процесс с предупреждением о потере форматирования и проверкой содержимого. Экспорт создаёт новый документ, а не заменяет существующий форматированный документ. Медиафайлы вместе с такими Markdown-записями не реплицируются. Форматы, разрешение конфликтов и ограничения опроса описаны в [контракте совместной работы](../validation/COLLABORATION_COMPLETION.md).

## Планирование с Calendar и Tasks

В настройках Integrations загрузите список календарей и списков задач, выберите нужные ресурсы и сохраните настройки. Если поиск не обнаружил ресурс, можно указать его идентификатор вручную. После изменения прав обновите подключение.

Рабочее пространство Tasks показывает локальные задачи и недельный планировщик. Локальные временные блоки доступны без сети. Срок задачи в Google Tasks не задаёт время в расписании; блоки со временем используют события Calendar. Выберите задачу хранилища, задайте начало и конец, затем сохраните локальный блок. Существующее событие со временем можно связать явно.

**Review bidirectional sync** сравнивает загруженные данные провайдера с локальными задачами и связанными блоками. Выберите направление для каждого изменения. Запись требует разрешения; конфликт ревизий требует повторной проверки. Календарь с доступом только для чтения можно просматривать и импортировать, но отправка событий в него отключена. Проверка охватывает загруженный период и явные связи, а не все события Google.

## Работа с Gmail

Включите плагин Gmail и откройте **Gmail Manager**. Ищите или обновляйте сообщения, загружайте следующие страницы и выбирайте сообщение для чтения обычного текста. Размер видимого списка ограничен; уточняйте запрос, если сообщений больше, чем он вмещает.

Импорт создаёт новую Markdown-заметку в исходном хранилище. Текст экранируется, чтобы содержимое письма не интерпретировалось как активный Markdown или HTML. Существующий файл не перезаписывается. Архивирование, перемещение в корзину и отправка — отдельные проверяемые действия у провайдера. Отправляется обычный текст; отказ в разрешении или ошибка отправки сохраняют черновик для исправления и повторной попытки.

## Отключение и восстановление

Отключение удаляет выбранный локальный набор учётных данных. Подготовленные удалённые проверки и кеш данной учётной записи очищаются, локальные заметки и временные блоки сохраняются. Связи с событиями не переиспользуются для другого аккаунта или календаря. Уже отправленный Google запрос может завершиться после отмены; смена аккаунта не позволяет его устаревшему результату заменить новое рабочее пространство.

Локальное отключение не отзывает общую авторизацию приложения в Google. Управляйте ею в разрешениях своего Google Account; отзыв может затронуть несколько подключённых сервисов.

| Проблема | Следующий шаг |
|---|---|
| Авторизация истекла или отсутствует | Повторно подключите нужный сервис и обновите данные. |
| Ресурс отсутствует или доступ запрещён | Проверьте аккаунт, ID и права общего доступа, затем повторите поиск. |
| Ошибка страниц или поиска ресурсов | Обновите данные, начав обход заново; частичный результат поиска отклоняется. |
| Настройки не сохранены | Сохраните конфигурацию перед открытием рабочего пространства по ссылке. |
| Удалённая ревизия изменилась | Загрузите её снова и подготовьте новую проверку перед записью. |

Интеграции остаются экспериментальными. Браузерные тестовые данные проверяют поведение приложения без доступа к Google-аккаунтам. Настоящий OAuth, общие диски и установленное настольное приложение требуют отдельной проверки у провайдера и на устройствах. Статус поддержки отражён в [реестре зрелости](../CAPABILITY-MATURITY.md), доказательства — в [записи проверки](../validation/GOOGLE-INTEGRATIONS-2026-10-09.md).
