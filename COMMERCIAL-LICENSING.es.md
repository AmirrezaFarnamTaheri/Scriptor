# Licencia comercial

Scriptor está disponible bajo **GNU AGPL-3.0-or-later**. La AGPL permite uso comercial, modificación, distribución y operación en red cuando se cumplen sus obligaciones. El proyecto no añade una restricción «no comercial» a la licencia concedida por la AGPL.

Una licencia comercial independiente puede ser útil para una organización que quiera:

- distribuir un producto propietario o una derivación closed-source sin obligaciones AGPL;
- operar un servicio de red modificado sin proporcionar el código fuente correspondiente exigido por la AGPL;
- negociar condiciones de garantía, indemnización, soporte, nivel de servicio, integración o redistribución.

Una licencia comercial es una **alternativa** a la AGPL, no un requisito para la actividad comercial que cumple con la AGPL.

Los mantenedores no deben afirmar que pueden relicenciar contribuciones salvo que el repositorio disponga de un contributor agreement aplicable o una concesión explícita.
