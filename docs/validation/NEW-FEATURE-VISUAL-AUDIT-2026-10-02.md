# New feature visual and interaction audit — 2026-10-02

Scope: Database Studio, Capture Reviewer, Reference Desk/Zotero, Asset Deck media, Publishing Studio and Drive collaboration. The full Visual Review reread is owned by the report analyst; this independent audit applies its recovered issue classes to the new workspaces. It does not substitute a fresh audit for the historical report or treat withdrawn screenshot allegations as verified defects.

The applied issue classes include narrow/zoom overflow, opaque surfaces, footer reachability, readable paths and Latin text in RTL, truthful empty/error/loading/cancellation states, keyboard containment, touch targets, disabled actions, source revision conflicts, and selection/save state. Existing research and media workflow tests additionally exercise loaded content, native-boundary failures, corrupt presets, external edits, reference-account changes and decoded local media.

## Evidence and limits

`e2e/new-feature-visual-audit.spec.ts` measures all six surfaces at 1440, 768, 375 and 320 CSS pixels, in LTR and RTL, checks Tab containment, hovered close overflow, Escape dismissal at 200% zoom, and captures both narrow directions. Machine measurements and traces are generated in `test-results/e2e/`; run output is retained in `artifacts/verification/new-feature-visual-audit.log`.

The first run was deliberately red and exposed real regressions rather than relaxing geometry thresholds. Intermediate reruns confirmed geometry repair but retained the real summary focus failure. The latest combined audit, Capture cancellation/frame navigation, six collaboration workflows, two Overleaf workflows and publication eligibility regression passed **12/12** (`artifacts/verification/drive-overleaf-final.log`). The corrected RTL tooltip screenshot was inspected. A final scoped Asset Deck touch-target audit additionally enforces its close/search/checkbox-label targets at both narrow widths; provider/native packaging limits still apply.

Initial geometry audit covers the entry state of Publishing and Collaboration, not an authenticated account or a real generated publication. Provider actions are mocked and never sent to external accounts. Forced RTL checks geometry and bidi behavior; it does not certify full product translation. Browser screenshot checks do not certify a packaged native application, a screen reader, or device performance.
