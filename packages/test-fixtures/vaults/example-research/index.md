# Research Index

Welcome to the **example research vault**. This vault demonstrates Scriptor's core features.

- [[daily/2026-01-15|Today's daily note]]

## Sections

### Daily Notes
Browse daily entries in the `daily/` folder. Each note uses the ISO date format and links back here.

### Projects
Active project notes live in `projects/`. Each has frontmatter tracking status and tags.

### References
Citation-backed notes in `references/`. These use CSL-JSON bibliography entries and can be exported with proper citations.

### Templates
Reusable note templates in `templates/`. Copy a template to start a new note with pre-filled structure.

## Features Demonstrated

- **Wikilinks**: `[[]]` syntax for internal links (see above)
- **Frontmatter**: YAML metadata at the top of each note
- **Daily notes**: ISO-date filenames in `daily/`
- **Citations**: `[@key]` citation syntax with bibliography file
- **Graph**: Open the graph view to see how notes connect
- **Search**: Use Ctrl+K to search across all notes
