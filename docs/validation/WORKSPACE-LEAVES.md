# Workspace leaves

The layout model stores up to 24 unique references in two groups, scoped by vault identifier. Only note/source paths or feature/plugin identifiers, group membership and active identity are serialized. Draft text, credentials, grants, process sessions and remote handles are excluded. The parser rejects unknown fields, duplicate identities, unsafe paths, oversized records and unsupported versions; unavailable references are removed with deterministic active fallback.

Restoration is inert. The hook serializes user transitions and asks the integration owner to approve before changing selection, closing or persisting. A vault change invalidates pending approvals. Storage denial leaves the current in-memory workspace usable. The owner must supply availability and dirty-editor/runtime guards and render the appropriate content; this module does not create independent mutable Markdown editors.

Tabs support manual keyboard activation with arrows, Home/End, Enter/Space and Delete to request guarded close. Separate explicit controls move between groups and reorder within a group. Ordinary buttons have 44-pixel targets; tabs scroll independently and controls wrap at narrow widths. At app zoom of at least 175%, one-row tabs and compact chrome use 32 CSS pixels (at least 56 displayed pixels); an opaque, bounded actions disclosure retains reorder and move operations. Escape closes the disclosure and restores focus. Embedded panels use their owning tab's Close control; nested dialogs retain their own control. Pure title headers and redundant activity launchers collapse at high zoom while unique header actions and metadata remain. The footer wraps at the narrowest effective width, and the command palette remains available. Directional keyboard navigation follows RTL.

Ten model behavioral tests cover malformed storage, per-group selection, capacity, inactive targeted close, plugin identity, unsupported writing moves and refused navigation targets. The initial implementation and subsequent fixes were preceded by failing behavioral checks. Per-group selected identities survive focus changes and restoration; closing a focused tab keeps the fallback identity consistent with its group selection. The single mutable writing host cannot open, move or restore in the side group. Existing tabs remain selectable at the capacity limit. Qualified plugin references contain exactly one separator with two bounded lowercase identifiers matching the plugin contract. Close/move/reorder guards identify the targeted leaf even when it is inactive. Revoked references are removed from proposed layouts so they cannot block unrelated navigation; the integration owner receives both layouts for lifecycle cleanup before approval. Tabs follow the application’s English, German or Persian locale and disable navigation/action controls while an owner decision is pending. The hook exposes pending/refused status and a bounded reason code without leaking feedback across vault generations; its completion callback runs only after commit. Integration browser evidence and full checks remain owned by the integrating change.
