# Заметки по визуальной проверке

Визуальная галерея проверенных эталонных снимков Windows — основное место для всех скриншотов, о которых говорится в этом документе. Каноническими являются раздел со скриншотами в README, `docs/assets/screenshots/README.md` и PNG-файлы в `docs/assets/screenshots/`; эта страница фиксирует **логику и дисциплину ревью**, а не дублирует изображения.

## Что гарантирует визуальный набор тестов

- Ленивая загрузка панелей, переполнение верхней панели, компактные макеты, фокус модальных окон и чистота консоли/сети проверяются исходным набором Playwright и должны повторно запускаться на зафиксированном кандидате релиза.
- Тёмная тема и контрольные точки 1024 / 768 / 375 px входят в матрицу; пара снимков рабочего пространства в README и адаптивные снимки документируют проверенные эталоны.
- Сценарии reader, tasks и kanban выполняются функциональным регрессионным набором Playwright и сохраняются как runtime-доказательства, когда соответствующие экспериментальные поверхности включены.
- Для fallback-состояний восстановления, клавиатурных popover, управления плагинами и готовности индексации предусмотрены отдельные снимки, на которые ссылается галерея.

## Дисциплина ревью

- Любое изменение эталона требует визуальной проверки diff и явной заметки ревью в пакете изменений.
- Устаревшие снимки заменяются только после проверки diff рецензентом; визуальные ошибки никогда не скрываются увеличением глобального допуска.
- Исходный набор Playwright и сохранённые PNG должны соответствовать друг другу. PNG являются артефактами документации и сами по себе не служат доказательством релиза. Авторитетными остаются точный commit, браузер, viewport и результат `pnpm test:visual`.
