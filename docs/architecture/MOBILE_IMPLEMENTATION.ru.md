# Реализация и проверка мобильного приложения

Мобильное приложение использует общий редактор и внутрипроцессный адаптер ядра Rust. Доступ к хранилищу ограничен областью мобильного хранилища; при сохранении заметок используются хеши содержимого и история, а не desktop-демон. Сенсорные элементы управления, направление текста и восстанавливаемые черновики имеют целевое браузерное покрытие.

Нативная компиляция для Android ARM64 и debug-сборка пакета проверены. Debug APK содержит `classes.dex`, `AndroidManifest.xml` и `lib/arm64-v8a/libscriptor_mobile_lib.so`; проверка целостности ZIP не выявляет повреждённых записей. Размер debug-пакета — 151 488 290 байт, включая неурезанную нативную библиотеку размером 144 335 032 байта. Это артефакт для разработки, а не оптимизированный по размеру release.

Независимая проверка пакета подтверждает нативную библиотеку AArch64 ELF64 (машина ELF 183). Установленное средство проверки подписей Android принимает APK с Signature Scheme v2 и одним подписантом. SHA-256 проверенного APK — `54eeb734857bce66273a2f30219e62dd1a85d2ee3fccb2d772a0a50a48d94e6e`; этот хеш идентифицирует локальный debug-артефакт и не является аттестацией релиза.

Стандартная команда Android столкнулась с ограничениями Windows на создание символических ссылок при размещении нативной библиотеки. Вспомогательный упаковщик проекта принимает уже скомпилированную нативную библиотеку, копирует её в сгенерированный staging-путь ARM64 и запускает сгенерированную сборку с принадлежащим проекту debug-ключом подписи. Он проверяет место назначения, восстанавливает окружение своего процесса, ограничивает количество workers и использование памяти и не изменяет глобальный Android keystore. Артефакты сборки и локальный debug-ключ игнорируются Git.

Сейчас ни одно Android-устройство не подключено. Установка на устройство, поведение жизненного цикла и разрешений, а также упаковка подписанного релиза ещё требуют проверки. Для компиляции iOS и проверки на устройстве необходим инструментарий Apple; их успешность на этом Windows-хосте не заявляется.
