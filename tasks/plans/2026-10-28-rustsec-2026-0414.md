# Remediate RUSTSEC-2026-0414 — pulldown-cmark

**Scope:** Shared Rust supply chain; independent of MAT-008 changes.

## Verified incident

The supply-chain job in [Scriptor CI #40661251859](https://github.com/AmirrezaFarnamTaheri/Scriptor/actions/runs/40661251859) failed the Cargo advisory audit on `pulldown-cmark 0.13.4`, RUSTSEC-2026-0414. The parser defect produces exponential event expansion with repeated empty-display wikilinks under `ENABLE_WIKILINKS`. No claim is made that Scriptor currently enables this option on every surface. The published fixed version is `0.13.5`.

- [x] Raise all direct Rust workspace manifest minimum versions to `0.13.5` without altering enabled features.
- [x] Update only the corresponding `Cargo.lock` package version and authoritative checksum.
- [x] Preserve `deny.toml` advisories rather than ignoring or suppressing this new vulnerability.
